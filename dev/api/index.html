API Reference

Client

JevClient.Client — Type
Client(; model, credential=EnvCredential("TYPESAFE_API_KEY"),
         retry=RetryPolicy(), timeout=TimeoutPolicy(), limits=ResourceLimits(),
         max_inflight=8)

Thread-safe client for the TypeSafe System One API. model is required and should normally be a versioned PinnedModel.

The client owns its credential provider, so close(client) closes that provider too. Call close(client) when finished, or use with_client to close it automatically. After close(client), any request throws JevClient.ClosedClientError.

source
JevClient.with_client — Function
with_client(f::Function; kwargs...)

Build a Client from kwargs, pass it to f, and return f(client). The client is always closed with Base.close in a finally block, including when f throws. Keyword arguments are forwarded to the Client constructor.

This mirrors Python's with statement; Base.close is never exported.

probability = with_client(
    model = PinnedModel("jev-1.13.0"),
    credential = EnvCredential("TYPESAFE_API_KEY"),
) do client
    response = system_one(client; state, questions)
    answer(response, "urgent").noul
end
source
JevClient.system_one — Function
system_one(client::Client; state, questions::QuestionSet,
           timeout=nothing, retry=nothing)::SystemOneResponse

Evaluate questions against state with the System One API and return a SystemOneResponse. timeout and retry narrow the client-level policies for this call; they cannot relax the client's resource limits. Passing a non-Client or a closed client throws JevClient.ClosedClientError.

source
JevClient.list_models — Function
list_models(client::Client)::ModelList

Return the models available to the client as a ModelList. A closed client throws JevClient.ClosedClientError.

Credentials

JevClient.EnvCredential — Type
EnvCredential(name)

Credential provider that reads the API key from the environment variable name at request time, so key rotation is picked up automatically. A missing, empty, or invalid value throws JevClient.CredentialError. The value is never logged and renders as <redacted>.

source
JevClient.StaticCredential — Type
StaticCredential(secret)

Credential provider that owns an in-memory copy of secret. close zeroes and empties the stored bytes on a best-effort basis. Prefer EnvCredential or CredentialCallback so the key is not held in process memory longer than necessary.

source
JevClient.CredentialCallback — Type
CredentialCallback(callback)

Credential provider that calls callback() before each request. callback must return an AbstractString; any other return value or a thrown exception becomes a JevClient.CredentialError without exposing the secret. Use this to integrate an OS keychain or key-management service. The external store's lifetime is owned by the callback provider and is not closed by JevClient.

source

Models

JevClient.PinnedModel — Type
PinnedModel(id)

Reference to a fixed, versioned model such as PinnedModel("jev-1.13.0"). Recommended for production because results are reproducible. Passing a moving alias such as "jev-latest" throws JevClient.LocalValidationError; use MovingAlias instead.

source
JevClient.MovingAlias — Type
MovingAlias(id)

Reference to a moving model alias such as MovingAlias("jev-latest"). The model behind the alias can change, so results are not reproducible. JevClient warns the first time a MovingAlias client is used.

source
JevClient.ModelInfo — Type
ModelInfo

Metadata for one model: name, description, and release_date.

source
JevClient.ModelList — Type
ModelList

List of ModelInfo entries returned by list_models.

Questions

JevClient.QuestionSet — Type
QuestionSet(items::Pair...)

Ordered collection of ID => question pairs, where each question is a Noul, Choice, or Score. IDs must be unique non-empty strings. Supports length, iteration, and questions[id].

source
JevClient.Noul — Type
Noul(instructions; criteria=nothing)

Yes/no (noul) question. Returns a NoulAnswer whose noul field is a probability. instructions is any non-null JSON-serializable value and criteria is an optional NoulCriteria.

source
JevClient.NoulCriteria — Type
NoulCriteria(; yes=nothing, no=nothing)

Criteria for a Noul question. At least one of yes or no must be given; each value is any JSON-serializable description of what satisfies that outcome.

source
JevClient.Choice — Type
Choice(instructions; criteria)

Multiple-choice question over 2 to 255 candidates. criteria is a collection of ID => description pairs, where each ID is a non-empty AbstractString. Returns a ChoiceAnswer with the selected ID and the full probability distribution. Treat the returned ID as untrusted and map it through an application-owned allowlist.

source
JevClient.Score — Type
Score(instructions; criteria)

Ordered score question with 2 to 10 labels, given as a vector of non-empty strings in ascending order. Returns a ScoreAnswer with the chosen level and its probability.

source

Responses

JevClient.SystemOneResponse — Type
SystemOneResponse

Result of system_one. Access answers by question ID with answer or response[id]. model is the resolved model ID, usage holds token counts, and request_id is the upstream request ID when present.

source
JevClient.NoulAnswer — Type
NoulAnswer

Answer to a Noul question. The field noul is the probability in [0, 1] that the criteria hold.

source
JevClient.ChoiceAnswer — Type
ChoiceAnswer

Answer to a Choice question. choice is the selected candidate ID, probabilities maps every candidate ID to its probability, and confidence describes the model's confidence in the selection.

source
JevClient.ScoreAnswer — Type
ScoreAnswer

Answer to a Score question. score is the chosen level, legend lists the labels in ascending order, probabilities gives the probability of each level, and confidence describes the model's confidence.

source
JevClient.Usage — Type
Usage

Token accounting for a System One request: input_tokens and output_tokens.

source
JevClient.answer — Function
answer(response::SystemOneResponse, id::AbstractString)::AbstractAnswer

Return the answer for the question id. Throws JevClient.LocalValidationError when the ID is unknown. Equivalent to response[id].

source
JevClient.request_id — Function
request_id(response::SystemOneResponse)::Union{Nothing,String}

Return the upstream request ID carried by response, or nothing when absent.

Policies and limits

JevClient.RetryPolicy — Type
RetryPolicy(; max_retries=2, initial_delay=0.5, max_delay=15.0, total_budget=60.0)

Retry settings for transient failures. max_retries must be between 0 and 5 and the delays and total_budget (seconds) must satisfy initial_delay <= max_delay <= total_budget <= 300. JevClient retries only HTTP 429 and 529 responses.

source
JevClient.TimeoutPolicy — Type
TimeoutPolicy(; connect=5.0, first_byte=15.0, attempt=30.0, total=60.0)

Per-call timeouts in seconds. Values must be finite and positive and satisfy connect <= attempt <= total and first_byte <= attempt. A call may pass a narrower TimeoutPolicy to system_one.

source
JevClient.ResourceLimits — Type
ResourceLimits(; max_request_bytes=1MiB, max_response_bytes=8MiB,
                 max_error_body_bytes=64KiB, max_json_depth=32,
                 max_string_bytes=1MiB, max_container_items=100_000,
                 max_questions=1024, max_question_id_chars=128,
                 max_model_id_bytes=128)

Bounded-resource limits enforced locally before and after a request. All values must be positive. Limits are intentionally not relaxed per call; build a new Client if different limits are required.

source

Errors

JevClient.JevError — Type
JevError

Abstract supertype of every error thrown by JevClient. Catch JevError to handle client failures without exposing request bodies or credentials. Concrete subtypes include JevClient.LocalValidationError, JevClient.CredentialError, JevClient.ClosedClientError, JevClient.TimeoutError, and the API error types.

source
